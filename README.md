# Electrohub Sales Data Analysis (Power BI)

This project is a complete Power BI dashboard built to explore Electrohub’s sales data. It highlights product performance, sales trends, discount analysis, and regional sales, while giving users the ability to drill down and filter data interactively.

---

## Dashboard Highlights
- **Top & Bottom 5 Products** by Sales, Profit, and Quantity Sold  
- **Sales Trends** shown across daily, monthly, quarterly, and yearly views  
- **Profit vs Net Sales** scatter plot to spot correlations  
- **Time Period Comparison** using slicers (Sales, Profit, Quantity)  
- **Discount Analysis** by promotion type (Flash Sale, Clearance, Seasonal, etc.)  
- **Sales by City/Region** with an interactive map  
- **Order-Level Drill Through** for detailed transactions  

---

## Workflow
- Loaded and cleaned raw data with **Power Query**  
- Built relationships in a **star schema** (Fact & Dimension tables)  
- Created **DAX measures** for KPIs like Sales, Profit, Discounts, and Quantity  
- Designed visuals (bar charts, line charts, scatter plots, maps) for easy insights  

---

## Sample Insights
- Sales peaked in **2023 (32M)** but dropped sharply in 2024  
- **Apple iPhone 14** led in both sales and profit across all categories  
- **Weekend Flash Sales** generated the biggest discount-driven volumes  
- Cities like **Delhi, Mumbai, and Bangalore** contributed most to overall sales  
- Categories such as **Personal Care** underperformed, showing room for growth  

---

## How to Use
1. Clone this repository  
2. Open the `.pbix` file in **Power BI Desktop**  
3. Use slicers and filters to explore products, customers, promotions, and dates
